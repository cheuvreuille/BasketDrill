Save to Google Drive

Connect through a Google Apps Script web app secured with your own API key. The key is kept only for this browser session—no Google sign-in is required here.

Apps Script setup

Create a script, add a Script Property named DRILLBOARD_API_KEY, deploy it as a web app running as you, and allow access to anyone with its URL.

function doPost(e) {
  const data = JSON.parse(e.postData.contents);
  const key = PropertiesService.getScriptProperties()
    .getProperty('DRILLBOARD_API_KEY');
  if (!key || data.apiKey !== key) {
    return ContentService.createTextOutput('Unauthorized');
  }
  const blob = Utilities.newBlob(
    data.content, 'application/json', data.fileName);
  const file = DriveApp.createFile(blob);
  return ContentService.createTextOutput(
    JSON.stringify({ ok: true, id: file.getId() }));
}
